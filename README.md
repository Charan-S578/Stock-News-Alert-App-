# Stock News Alert App 📈📰

A Python automation project that tracks Tesla stock price changes using the Alpha Vantage API. When the stock price changes beyond a specified percentage, the app fetches the latest related news articles from NewsAPI and sends SMS alerts directly to your phone using Twilio.

---

## Features 🚀

- Track daily stock price movements
- Calculate percentage difference automatically
- Fetch latest company news articles
- Send SMS notifications using Twilio
- Real-time stock monitoring automation

---

## Technologies Used 🛠️

- Python
- Requests Library
- Alpha Vantage API
- NewsAPI
- Twilio API
